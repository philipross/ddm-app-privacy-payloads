## Contributions are encouraged!

* If you would like to contribute, please create a branch and submit a pull request.
* If you want to add a new entry, but aren't sure how to structure it, please submit it as an [application request.](https://github.com/philipross/ddm-app-privacy-payloads/issues/new/choose)
* If you want to contribute to correct an entry/fix a bug, please report it as a [bug report](https://github.com/philipross/ddm-app-privacy-payloads/issues/new/choose) and include the issue number in the merge request.

## Template

I've created a [NewAppTemplate.json](https://github.com/philipross/ddm-app-privacy-payloads/blob/main/NewAppTemplate.json) template to help provide a consistent structure to the contents in this repository.<br>
This template has an array for macOS, and a separate array for iOS/iPadOS where some keys are only applicable to specific platforms.<br>
Use this if you wish, but at minimum please keep the same structure.<br>
Pull requests that overwrite this template will not be accepted until the template is restored.

## Repository structure

To help keep some structure within the repository, I've attempted to structure it by Application _type_ - e.g. Browsers, VC applications, IDEs - rather than a monolithic list of software titles.<br>
Please help to keep some structure to the repository when contributing so it maintains ease of use when trying to find an application entry.
